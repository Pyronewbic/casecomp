Queue Auto-Join — Test Harness

Simulated queue pages using real detection mechanisms (Incapsula, Queue-it, PerimeterX).

Setup

  1. chrome://extensions — Developer mode ON — Load unpacked — select extension/
  2. Run node extension/test/enable-local-testing.js to patch manifest for localhost
  3. Reload the extension, then open pages below

Simulates the Incapsula waiting room with a hidden iframe (src=/_Incapsula_Resource), a #ttw element showing HH:MM:SS wait time, and a position counter. Auto-redirects when done.
